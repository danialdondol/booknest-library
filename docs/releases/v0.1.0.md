# BookNest v0.1.0

**A calm, accessible small-library desk — now a production-quality static repository.**

This release rebuilds the original IMS566 prototype without changing its assignment scope: protected
demo login, dashboard, book catalogue and member register.

## Highlights

- **One-command start:** `npm start` installs dependencies on first run and opens Vite.
- **Fail-closed auth:** versioned session storage, eight-hour expiry, guarded pages, bfcache re-check
  and no protected-content flash.
- **Deep-linkable catalogue:** search, category/status filters and sort live in the URL.
- **Accessible by default:** `aria-sort` header buttons, live result counts, labelled controls,
  chart data tables, native details dialog, focus return and reduced motion.
- **Distinctive design:** self-hosted Fraunces/Manrope typography, warm paper palette and a custom
  responsive system with no CDN dependency.
- **Honest security boundary:** the demo auth, its risks and the production requirements are
  documented in the UI, README, SECURITY.md and ADR-0002.

## Quality

- 71 Vitest unit tests; 97.25% line coverage on the pure domain/auth layer.
- 25 Playwright tests against the production build.
- Axe scans on every page and the open dialog: 0 serious/critical violations.
- ESLint and Prettier clean.
- Build verifier checks all five pages and relative assets.

## Install

```bash
npm start
```

Demo login: `admin` / `admin123` or `librarian` / `lib2026`.

## Known limitations

- Authentication is client-side and not a security boundary.
- Records are static; edits and loans do not persist.
- GitHub Pages cannot set HTTP security headers.
- The ESLint development dependency chain currently has a moderate `minimatch` advisory with no
  compatible upstream fix yet.
